# ToolStack

ToolStack is a static website containing free, browser-based SEO and writing utilities. It is built with HTML, CSS, and client-side JavaScript; there is no package manager or server-side runtime required to preview the site.

## Included tools

- **Meta tag preview** — preview search and social metadata.
- **Keyword density checker** — inspect word and phrase frequency.
- **Readability checker** — estimate readability from text.
- **SSL checker** — SSL guidance/checking page.
- **Word counter** — count words and characters.
- **Heading analyzer** — inspect heading hierarchy.

The site also includes a static blog under `blog/`.

## Run locally

From the repository root, start any static HTTP server. For example, with Python:

```powershell
python -m http.server 8000
```

Open `http://localhost:8000/`. Some navigation links use `/toolstack/` paths for GitHub Pages project-site hosting; check the deployment base path if hosting at a domain root or another subpath.

## Validate changes

```powershell
python scripts/check_site.py
```

The checker verifies local HTML links and assets resolve within the repository. It uses only Python's standard library.

## Deployment

`vercel.json` and `deploy.sh` contain deployment configuration/examples. Review the target account and deployment settings before publishing; the repository does not include secrets or deployment credentials.

The tools are intended to run in the browser. Review each tool's implementation before making broader privacy claims, particularly if adding third-party scripts or remote requests.
